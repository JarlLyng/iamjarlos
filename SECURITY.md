# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Email:** [jarl@forteadvice.com](mailto:jarl@forteadvice.com)

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- Any potential impact

I will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for confirmed vulnerabilities.

## Scope

This policy applies to the [iamjarl.com](https://iamjarl.com) portfolio site and its source code.

## Supported Versions

Only the latest version deployed on `main` is actively maintained.
