# iamjarlOS

The built static site of **iamjarlOS**, a portfolio presented as an operating system, live at
[os.iamjarl.com](https://os.iamjarl.com).

This repository holds only the generated output that GitHub Pages serves. It is replaced as a
whole on every deploy, so changes made here directly don't survive the next one.
